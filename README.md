# 🌐 Personal Portfolio Website

A responsive personal portfolio website built to showcase my projects, certifications, and technical skills. The website is developed using HTML, CSS, and JavaScript, then containerized with Docker and served using Nginx.

## 🚀 Live Demo

🔗 https://ritabayuni.github.io/Portfolio-Website_Rahimi-Illong-Tabayuni/ 

## ✨ Features

- Responsive design
- About Me section
- Project showcase
- Certifications section
- Contact information
- Dockerized deployment with Nginx

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Docker
- Nginx
- Git & GitHub

## 📦 Run Locally

Clone the repository:

```bash
git clone https://github.com/RITabayuni/Portfolio-Website_Rahimi-Illong-Tabayuni/
cd REPOSITORY_NAME
```

Run with Docker:
_**docker compose up --build**_

Open your browser:
**_http://localhost:8080_**
